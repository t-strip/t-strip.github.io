T-Strip Wiki

Everything you need to install, configure and extend the endless terminal multiplexer.

T-Strip is a scrollable tiling terminal multiplexer built in Go. This wiki is the long-form companion to the interactive demo on the homepage. It walks through installation, the configuration file, the complete key binding reference, workspaces and layout, copy mode, scrollback, sessions, the status bar and the internals of the project.

About the wiki

T-Strip places panes in columns on an endless horizontal strip instead of squeezing every terminal into a fixed grid. The viewport glides to whatever has focus, so you can keep a large working set open without losing your place. The wiki explains how that model works in practice: how to install the binary, how to shape your configuration, how to move between columns and panes, and how to use copy mode, scrollback and sessions without breaking flow.

If you are new to T-Strip, start with Getting Started, then read Key Bindings and Workspaces and Layout. For a quick look at the interface before installing, open the interactive demo on the homepage. The source code and issue tracker live on GitHub.
